# Future Ideas

This document tracks enhancements that should not complicate the first implementation of the recipe rotation app. These ideas are intentionally non-blocking future scope.

## Shopping List Integrations

- Google Keep shopping list export or sync.
- Start with one-way export to Google Keep before considering two-way sync.
- Export shopping lists to plain text.
- Export shopping lists to Markdown.
- Share shopping lists with another person.

## Recipe Management

- Recipe tags.
- Cuisine labels.
- Seasonal recipes.
- Favorite recipes.
- Archived recipes.
- Recipe difficulty.
- Prep time.
- Cook time.
- Recipe source links.
- Recipe images.

## Meal Planning

- Avoid repeating similar cuisines in the same plan.
- Support multiple meals per day.
- Support skipped calendar days with explicit dates.
- Support manually pinned recipes.
- Support guests or temporary people-count overrides per recipe.
- Support freezer meals.
- Support batch cooking.
- Support rules such as vegetarian days or quick-cook days.

## Pantry And Inventory

- Pantry tracking.
- Owned ingredients.
- Pantry staples.
- Exclude pantry staples from the shopping list.
- Low-stock reminders.
- Inventory expiration dates.

## Import And Export

- Import recipes from URLs.
- Import recipes from pasted text.
- Export recipes as Markdown.
- Export recipes as JSON.
- Print-friendly weekly plan.
- Print-friendly shopping list.

## Nutrition And Metadata

- Calories.
- Protein.
- Carbs.
- Fat.
- Allergens.
- Dietary labels.
- Cost estimates.

## UX Improvements

- Mobile-first shopping mode.
- Checked-off shopping list state synced across devices (currently per-device in `localStorage`).
- Dark mode is implemented; refine contrast if needed.
- Offline-friendly behavior.
- Drag-and-drop meal planning.
- Calendar view.
- Quick duplicate recipe action.
